# 视觉与交互设计

## 目标

让网页“看起来就是为这个主题做的”，而不是一张通用模板换文案。

## 风格决策

| 主题气质 | 配色方向 | 排版与质感 |
| --- | --- | --- |
| 旅行 / 美食 | 湖蓝、竹绿、暖橙；浅色底 | 大图留白、圆角卡片、轻阴影 |
| 健身 / 运动 | 深色底、荧光青/橙高对比 | 粗体数字、进度条、卡片分块 |
| 学习 / 项目 | 蓝紫冷色、深色科技感 | 时间线、阶段标签、数据卡片 |
| 读书 / 成长 | 米色纸感、棕金、墨绿 | 长文行距、引用块、章节导航 |
| 活动 / 产品 | 高饱和强调色 | 大标题、流程条、卖点分栏 |

## 设计规则

1. **一个主色 + 一个强调色**：主色用于导航与按钮，强调色用于标签、进度、重点数字。
2. **层级清晰**：页面标题 28-40px，模块标题 18-22px，正文 14-16px；标题与正文对比明显。
3. **留白优先**：模块间距 24-32px，避免信息挤在一起；内容宽度控制在 1100-1200px。
4. **卡片不过度**：同一屏不要超过 6 张卡片；每张卡片只表达一个主题。
5. **交互有反馈**：hover 变色、当前导航高亮、筛选即时生效、折叠有过渡。
6. **响应式**：移动端单列，导航可横向滚动，字号不缩小到不可读。
7. **可访问性**：正文与背景对比度足够；不要仅用颜色传达状态；输入框有 placeholder 与可见边框。

## Tailwind 实施建议

- 背景与文字成对使用：`bg-zinc-950 text-zinc-100` / `bg-stone-50 text-stone-900`。
- 强调色用内联 style 绑定规划中的 palette，避免写死 Tailwind 色阶。
- 卡片：`rounded-2xl border p-6`，深色用 `border-white/10 bg-white/[0.04]`。
- 内容网格：`grid gap-5 md:grid-cols-2`，避免三列导致窄屏拥挤。

## 输出检查

- 首屏能看出主题，不需要阅读长文。
- 配色不超过 3 个主色相。
- 卡片、列表、标签的层级关系清楚。
- 手机宽度下无横向滚动、无文字溢出。
