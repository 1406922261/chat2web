# 网页测试与验收

## 测试前置

1. 确认开发服务器已启动，拿到真实地址（`dev_server` 返回的 `http://127.0.0.1:端口`）。
2. 确认 `npm install` 已完成，否则先安装依赖。
3. 不要用静态截图或想象代替真实访问。

## 基础测试（必须）

- 调用 `web_test` 访问首页，确认 HTTP 状态正常、返回内容非空。
- 逐个访问规划中的每个路由，确认没有 404。
- 检查页面是否包含关键内容（主题名、至少 2 个模块标题）。

## 深度测试（可用 Playwright MCP）

1. 打开首页，截图确认首屏渲染。
2. 点击导航到每个页面，确认路由切换正常。
3. 测试筛选/搜索/折叠等交互是否生效。
4. 收集浏览器控制台错误；有报错必须修复。
5. 用移动端宽度检查是否横向溢出。

## 失败处理

- **编译错误**：读取 `shell_exec` 输出的第一条错误，定位文件与行号后修复。
- **404 / 空白页**：检查路由 path、`main.tsx` 挂载、组件导出。
- **样式错乱**：检查 Tailwind 指令是否引入、类名是否拼写正确。
- **依赖缺失**：执行 `npm install <包>` 后重启 dev server。
- 修复后重新测试，最多 3 轮；仍失败要如实报告，不能宣称成功。

## 验收清单

- [ ] 首页可访问，主题清晰
- [ ] 所有导航页面可打开
- [ ] 每页至少 2 个有内容的模块
- [ ] 交互功能真实可用
- [ ] 无控制台报错
- [ ] 移动端无横向滚动
- [ ] 待补充信息有明确标注
